## 一、你现在这段代码的问题在哪？

```
const resData = response.data;
const config = response.config;

// ✅ 公共接口直接放过
if (config.url?.startsWith("/app-api/v1/auth")) {
  return resData;
}

// OAuth2 token 接口失败，直接 reject
if (config.url?.includes("/oauth2/token")) {
  return Promise.reject(resData);
}
```

### ❌ 问题 1：把「登录接口」当成了公共接口

```
/app-api/v1/auth
```

通常这个路径里包含：

- 

  登录

- 

  刷新 token

- 

  获取验证码

- 

  退出登录

👉 **这些接口 ≠ 公共接口**

👉 尤其 **`/oauth2/token`往往就在它下面**

------

### ❌ 问题 2：逻辑顺序是“反的”

你现在顺序是：

1️⃣ 先放过 `/app-api/v1/auth`

2️⃣ 再判断 `/oauth2/token`

👉 结果是：

```
/oauth2/token
└─ 命中 /app-api/v1/auth
   └─ return resData ✅（直接放行）
```

**永远不会走到 `Promise.reject`**

⚠️ 这就是为什么你之前看到：

```
{ code: "00000", data: {...}, msg: "一切ok" }
```

明明是 token 接口，却被当成普通业务接口“放过了”。

------

## 二、正确的逻辑顺序（非常关键）

### ✅ **OAuth2 接口优先判断**

```
const resData = response.data;
const config = response.config;

// ✅ 1️⃣ OAuth2 token 接口（最高优先级）
if (config.url?.includes("/oauth2/token")) {
  // 登录 / 刷新成功，直接返回 data（不要包 code/msg）
  return resData.data ?? resData;
}

// ✅ 2️⃣ 真正的公共接口（不走 token 校验）
if (config.url?.startsWith("/public/")) {
  return resData;
}
```

------

## 三、为什么 `/oauth2/token`不能走公共接口逻辑？

| 原因                  | 说明                       |
| --------------------- | -------------------------- |
| 它是认证接口          | 不应该参与业务 code 判断   |
| 返回结构特殊          | 不是 `{ code, data, msg }` |
| 刷新失败要触发 logout | 不能被“放过”               |

## 四、你这个场景下的「正确完整版」

### ✅ 推荐你直接用这一版（稳定）

```
const responseInterceptor = (response: any) => {
  const resData = response.data;
  const config = response.config;

  // ✅ 1. OAuth2 token 接口（最重要）
  if (config.url?.includes("/oauth2/token")) {
    // 成功：返回 token 数据
    if (resData.code === ResultCodeEnum.SUCCESS) {
      return resData.data;
    }
    // 失败：直接 reject，让 refresh 逻辑处理
    return Promise.reject(resData);
  }

  // ✅ 2. 公共接口直接放行
  if (config.url?.startsWith("/public/")) {
    return resData;
  }

  // ✅ 3. 401 / token 失效
  if (
    response.statusCode === 401 ||
    resData.code === ResultCodeEnum.TOKEN_INVALID ||
    resData.code === "A0230"
  ) {
    handleTokenExpiredSync();
    return Promise.reject(resData);
  }

  // ✅ 4. 正常业务接口
  if (resData.code !== ResultCodeEnum.SUCCESS) {
    uni.showToast({
      title: resData.msg || "业务处理失败",
      icon: "none",
    });
    return Promise.reject(resData);
  }

  return resData.data;
};
```
