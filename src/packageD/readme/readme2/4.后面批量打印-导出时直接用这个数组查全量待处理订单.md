明白了，那 `statuses` 先留着，后面批量打印/导出时直接用这个数组查全量待处理订单。

那现在你的逻辑就是：

| 场景                        | 用 `status` 单值 | 用 `statuses` 数组                |
| --------------------------- | ---------------- | --------------------------------- |
| 页面筛选查看                | ✅ 单选           | ❌ 不用                            |
| 后面批量打印/导出全部待处理 | ❌                | ✅ 到时候直接传 `PENDING_STATUSES` |

现在代码不用动，`getFilterParams` 里那段 `statuses` 分支留着不碍事，只是日常筛选不走它而已。等后面做批量打印的时候，单独构造参数：

```ts
const printAllPending = () => {
  const params = {
    statuses: PENDING_STATUSES, // [0,1,6]
    // 不传时间 = 查所有
  };
  // 调打印/导出接口
};
```

到时候直接拿来用就行，不用再改筛选逻辑 👍
