啊，我明白了！你的意思是：

`pending` 模式就是一个"待处理"的壳，里面状态栏可以切不同的具体状态。点"全部待处理"快捷按钮时，默认高亮"待发货"并只查待发货，状态栏再切别的就查别的。

也就是说：

| 操作             | 实际行为                                                     |
| ---------------- | ------------------------------------------------------------ |
| 点"全部待处理"   | `filterMode=pending`，`status=PAID`，时间不限 → 只查待发货   |
| 状态栏点"待付款" | `filterMode=pending`，`status=UNPAID`，时间不限 → 只查待付款 |
| 状态栏点"售后中" | `filterMode=pending`，`status=SERVICING`，时间不限 → 只查售后中 |

根本不需要 `statuses` 数组，永远只传单个 `status`。

那你的 `getFilterParams` 应该改成：

```ts
const getFilterParams = () => {
  const params: any = {
    ...advancedFilter.value,
  };

  if (filterMode.value === "pending") {
    // pending 模式：时间不限，只按单个状态查
    if (activeStatus.value) {
      params.status = activeStatus.value;
    }
    // 不传 startDate / endDate
  } else {
    // all / single 模式：带时间
    params.startDate = dateRange.value.start;
    params.endDate = dateRange.value.end;

    if (activeStatus.value) {
      params.status = activeStatus.value;
    }
  }

  return params;
};
```

`onPendingClick` 保持你原来的写法就行：

```ts
const onPendingClick = () => {
  filterMode.value = "pending";
  activeStatus.value = OrderStatusEnum.PAID; // 默认高亮待发货

```

这样：

• 点"全部待处理" → 查 `status=PAID`，无时间限制 → 只出待发货订单 ✅

• 状态栏切"待付款" → `activeStatus=UNPAID`，还是 `filterMode=pending` → 查 `status=UNPAID` ✅

• 点"今日" → `filterMode=all`，`status=PAID` + 今天日期 → 今天待发货 ✅
