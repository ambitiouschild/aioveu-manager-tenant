------

## 一、先明确：什么是“待处理”

你现在的逻辑里：

```
pendingOrders = statistics.pendingCount
```

但**没有一个统一的“待处理状态”**。

通常“待处理” = 需要商家操作的订单，比如：

| 状态      | 含义   |
| --------- | ------ |
| UNPAID    | 待付款 |
| PAID      | 待发货 |
| SERVICING | 售后中 |

你可以定义一个**组合状态**：

```
// 待处理 = 需要商家操作的订单
const PENDING_STATUSES = [
  OrderStatusEnum.UNPAID,
  OrderStatusEnum.PAID,
  OrderStatusEnum.SERVICING,
] as const
```

------

## 二、核心思路（关键）

> **后端必须支持 `status`传数组**

因为“待处理”不是单一状态，而是多个状态的组合。

### 前端传参变化

原来：

```
status: activeStatus.value   // string | null
```

改成支持数组：

```
statuses: activeStatuses.value // string[] | null
```

## 三、具体实现步骤

### 1. 新增“待处理”筛选类型

```
type FilterMode = 'single' | 'pending' | 'all'

const filterMode = ref<FilterMode>('all')
const activeStatus = ref<string | null>(null)
```

### 2. 定义待处理状态组合

```
const PENDING_STATUSES = [
  OrderStatusEnum.UNPAID,
  OrderStatusEnum.PAID,
  OrderStatusEnum.SERVICING,
]
```

### 3. 修改状态点击逻辑

```
const onStatusClick = (status: string | null) => {
  if (status === null) {
    // 点击“全部”
    filterMode.value = 'all'
    activeStatus.value = null
  } else {
    // 点击单个状态
    filterMode.value = 'single'
    activeStatus.value = status
  }
  loadOrders(true)
  loadOrderStatistics()
}

// ✅ 新增：一键待处理
const onPendingClick = () => {
  filterMode.value = 'pending'
  activeStatus.value = null
  loadOrders(true)
  loadOrderStatistics()
}
```

------

### 4. 修改请求参数构造

```
const getFilterParams = () => {
  const params: any = {
    startDate: dateRange.value.start,
    endDate: dateRange.value.end,
    ...advancedFilter.value,
  }

  if (filterMode.value === 'pending') {
    // ✅ 传数组给后端
    params.statuses = PENDING_STATUSES
  } else if (filterMode.value === 'single' && activeStatus.value) {
    params.status = activeStatus.value
  }
  // 'all' 不传 status

  return params
}
```

### 5. 后端接口要求

后端 `/listOrdersWithPage`需要支持：

```
{
  "statuses": ["UNPAID", "PAID", "SERVICING"]
}
```

如果后端**暂时不支持数组**，有两个兜底方案：

------

## 四、后端不支持数组时的兜底方案

### 方案 A：前端多次请求合并（不推荐，慢）

```
const loadPendingOrders = async () => {
  const results = await Promise.all(
    PENDING_STATUSES.map(status =>
      listOrdersWithPage({
        ...baseParams,
        status,
      })
    )
  )
  // 合并去重
  orderList.value = mergeOrders(results)
}
```

------

### 方案 B：后端加一个虚拟状态 `PENDING`（✅ 推荐）

让后端支持：

```
{ "status": "PENDING" }
```

后端自己映射为：

```
if ("PENDING".equals(status)) {
    wrapper.in("status", "UNPAID", "PAID", "SERVICING");
}
```

前端只传一个值，最简单。

## 七、总结一句话

> **“一键查看所有待处理订单” = 把多个状态组合成一个虚拟筛选条件，传给后端**

| 层级 | 做法                                    |
| ---- | --------------------------------------- |
| 前端 | 定义 `PENDING_STATUSES`组合             |
| 请求 | 用 `statuses`数组 或 虚拟状态 `PENDING` |
| UI   | 状态栏数字 / 快捷筛选 可点击            |
| 后端 | 支持 `IN`查询                           |
